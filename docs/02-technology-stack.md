# 2. Technology Stack

- **Backend Framework:** Spring Boot (Java 17+)
- **Microservices Architecture:** Spring Cloud (Gateway, Eureka for Service Discovery)
- **Database:** PostgreSQL (Database-per-service pattern)
- **Message Broker:** Apache Kafka (Asynchronous processing)
- **Caching & Locking:** Redis (Seat locking)
- **Frontend Web:** React.js, Tailwind CSS, QueryClient
- **Frontend Mobile:** Flutter, Dart, BLoC or Riverpod, QR scanner package (`mobile_scanner`).
- **Payment Integration:** VNPay, MoMo.
- **Infrastructure:** Docker, Kubernetes, AWS/Google Cloud.
